# Quantum-Assisted Physics-Informed Neural Network (QAPINN)
**BQP WISER Quantum Challenge 2026**

## Overview
This repository contains the source code and generated data artifacts for solving the 1D Viscous Burgers' Equation using a hybrid Quantum-Assisted Physics-Informed Neural Network (QAPINN). 

The primary objective of this project is to analyze the impact of quantum layer expressivity on PDE convergence and network learning dynamics. We compare a purely Classical Physics-Informed Neural Network (cPINN) baseline against 3-qubit, 4-qubit, and 5-qubit hybrid quantum variants. 

## Repository Structure

### 1. `/notebooks`
Contains the Google Colab training notebooks for all model variants.
* `01_cPINN_Baseline.ipynb` - Classical PINN baseline.
* `02_QAPINN_4_qubit.ipynb` - Hybrid model with a 4-qubit VQC layer.
* `03_QAPINN_3_qubit.ipynb` - Hybrid model with a 3-qubit VQC layer (reduced expressivity).
* `04_QAPINN_5_qubit.ipynb` - Hybrid model with a 5-qubit VQC layer (increased expressivity).

### 2. `/results`
Contains the exported NumPy arrays (`.npy` and `.npz`) generated by the notebooks. These files are used for Explainable AI (XAI) and visual analysis.
Each model variant outputs 5 specific artifacts:
1. `predictions_[model].npy`: The predicted fluid velocity u(x,t) across the 256x100 spatial-temporal grid.
2. `activations_[model].npz`: Captured hidden layer activations for neuron collapse analysis.
3. `loss_curve_[model].npy`: The total physics-informed loss recorded per epoch.
4. `weights_[model].npz`: Flattened network weights for loss landscape visualization.
5. `pde_residual_[model].npy`: The raw mathematical error of the PDE evaluated across the grid (used for spatial error heatmaps).
* `ground_truth.npy`: The exact analytical solution to the Burgers' equation for benchmarking.

## Reproducibility Instructions
To ensure 100% mathematical reproducibility for evaluation, **strict random seeds (`seed = 42`)** have been enforced across all PyTorch, NumPy, and Python random initializations. 

**To reproduce the training and generate the data artifacts:**
1. Open any of the `.ipynb` files in Google Colab.
2. Ensure the hardware accelerator is set to GPU (`Runtime > Change runtime type > T4 GPU`).
3. Run the first cell to install dependencies.
4. Select `Runtime > Run all`.
5. The model will train for 1,000 epochs, and the resulting 5 artifact files will be automatically generated and saved to the local Colab file system. 

## Neural Network Architecture Details

### The Physics Problem
* **Equation:** 1D Viscous Burgers' Equation
* **Grid Size:** 256 x 100 evaluation points.
* **Loss Function:** L_Total = L_PDE + L_IC + L_BC calculated via PyTorch Autograd.

### Hybrid VQC Design
For the quantum models, the first classical hidden layer is replaced by a Variational Quantum Circuit (VQC) implemented via **PennyLane**:
* **Data Encoding:** Classical inputs are scaled to [-pi, pi] and encoded into the quantum state using `AngleEmbedding` with Y-axis rotations.
* **Trainable Ansatz:** A 2-layer (`n_layers=2`) heavily entangled circuit. Each layer applies general parameterized rotations (`qml.Rot` utilizing phi, theta, omega weights) to every qubit, followed by a ring-topology of CNOT gates.
* **Measurement:** Expectation values of the Pauli-Z observables for all qubits are extracted and passed to the subsequent classical layers.
* **Classical Stack:** PyTorch Linear layers utilizing `Tanh` activations to maintain the twice-differentiable requirement for solving second-order PDEs.
